Zunaira Faisal personal portfolio

**Project description:**
This portfolio is created for INFR3120 – Web and Script Programming. The design uses a beige, brown and cream colour theme (Colour scheme from Adobe).

**Pages**
The portfolio includes four main pages:
1. Home: Introduction to me and my portfolio.
2. About Me: Information about my background and interests.
3. Projects: Displays my projects and previous work.
4. Contact Me: Provides contact information.


**Technologies Used:**
1. Node.js
2. Express.js
3. EJS
4. HTML
5. CSS
6. Bootstrap
7. Font awesome
8. Git and Github
